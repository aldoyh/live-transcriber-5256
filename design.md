# نصّ — professional transcription console
User revision: neutral charcoal #111315, subtle muted red #d76565 on the brand mark, live/recording indicator, selected navigation edge and errors. Keep restrained green #b5d895 for the primary capture action and success only. No green washes, gradient cards, slogans, commercial containers, promotional sidebar or hero. All copy is literal Arabic, RTL; self-hosted Tajawal, readable 13–16px controls, monospace timestamps and LTR URLs.
Layout: narrow right navigation rail, compact top bar with database sync status. A single source/control strip above a large document editor with a quiet metadata/activity inspector. Metrics form one inline status bar, not three cards. Sessions and activity use dense, readable tables and pagination. Mobile collapses navigation into a sheet and stacks inspector after editor; minimum 40px button targets.
Persistence: managed SQLite/libSQL through Drizzle. Tables store session snapshots and append-only operational activity: source, title, transcript revisions, timings, capture lifecycle, transcription requests/results/errors, exports, copy, navigation, preferences and consent. No raw audio/video retention. Anonymous workspace capability is generated on-device, hashed on the server, and scopes all rows; no global public listing. Local storage is an offline fallback and migration source, not the primary database. Honest saving/offline status and retry controls.
Capture: retain native Chrome tab sharing and WAV chunks about 12s; no link-only ingestion or permission bypass. Start from an embedded preview opens standalone; audio engine resumes during click. Show setup phase, source diagnostics, silence/errors and processing queue. SRT timestamps remain capture-relative and approximate.
